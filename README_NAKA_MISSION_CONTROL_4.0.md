# NAKA Mission Control 4.0

Aerospace-inspired global license operations dashboard for NAKA.

## Highlights
- Mission-control / telemetry visual system
- Live-style system status panel
- Radar-inspired operational display
- Quick command surface
- Premium glass / HUD visual language
- Existing license API, Supabase, authentication, CRUD, CSV export, audit, and Roblox links preserved

## Deployment
Deploy the repository root to the existing Vercel project `licensi-kit-naka`.
Do not commit `.env` files or private keys. Keep production secrets in Vercel Environment Variables.
